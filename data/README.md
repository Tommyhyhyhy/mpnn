# Dữ liệu

`reuter+50+50.zip` là bộ **Reuter_50_50** (Liu, Z., 2011) lấy từ UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/217/reuter+50+50 (giấy phép CC BY 4.0).

Không cần giải nén thủ công: notebook `DoAn_MoPhong.ipynb` và `app_demo.py` tự giải nén
ra `data/C50train/` và `data/C50test/` ở lần chạy đầu.
